Core rhythm

Concentration / maintenance
Archer prepares before release. Mage invests after release by keeping a live link to the bolt. Damage, healing and interruption numbers appear over heads on impact.
Movement stick
Phone: inner circle is walk, 30% slower than old movement, no AP regen penalty. Run now requires pushing near the outer rim; accidental edge drift should not drop Guard Mass. Outer run is 30% faster and has no AP regen.
Tank mechanics
Warrior: walk/block into pressure to build Guard Mass. Frontal block strongly reduces hits; high mass converts weak pressure into grazes. Good bash/cleave reinforce mass; whiffs, rear hits and running break it.
Desktop controls
WASD move, mouse aim, LMB action/fire, RMB block, Space dodge. Number keys select actions. Z/X/C switch Warrior/Archer/Mage.
Spawner zones
Colored 10×10 corner zones spawn monsters while you stand inside. Corners produce warrior, archer, mage, and random enemies in common/high-HP/dodger order.
